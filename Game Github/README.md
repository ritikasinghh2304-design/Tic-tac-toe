# Tic Tac Toe 🎮

A basic Tic Tac Toe game created using HTML, CSS and JavaScript.

## Features

- Two-player game
- X and O turns
- Winner detection
- Draw detection
- Restart button

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Play

1. Player X starts the game.
2. Players take turns selecting a box.
3. The first player to get three symbols in a row wins.
4. If all boxes are filled without a winner, the game is a draw.
